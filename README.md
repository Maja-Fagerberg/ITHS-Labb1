# ITHS-Labb1

Labb1 på IT-högskolan i kursen NEUG26 - Programmering med C#

Uppgiften kortfattat: 
Ett program som hittar tal i en textsträng. Talen ska börja och sluta på samma siffra, utan att det finns något annat tecken emellan. Start- och slutsiffran får heller inte förekomma emellan.
Strängen skrivs sedan ut flera gånger där de hittade talen markeras med röd text och resten med annan färg. Sist adderas de hittade talen ihop och summan skrivs ut.
